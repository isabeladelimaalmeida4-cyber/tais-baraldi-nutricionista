# Tais Baraldi Nutricionista

Site de uma página da nutricionista Tais Baraldi, em Rondonópolis - MT.

O site inteiro está em `index.html` (HTML, CSS, JavaScript e fotos no mesmo arquivo). A abertura em 3D usa a biblioteca three.js, carregada de uma CDN, e as fontes vêm do Google Fonts.

## Pendências antes de divulgar

- Preencher o número do CRN (aparece na seção "Sobre" e no rodapé).
- Confirmar com a Tais as etapas do acompanhamento e completar formação e especializações.
- Trocar as fotos pelos arquivos originais (as atuais são recortes do Instagram).
- Com o endereço final definido, acrescentar o link canônico e a imagem de compartilhamento, conforme o comentário no topo do `index.html`.
